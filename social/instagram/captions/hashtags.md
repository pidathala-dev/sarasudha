# Hashtag strategy

Conservative and relevant — not spammed. Post as a first comment, not stuffed
into the caption itself (keeps the caption readable).

## Primary set (use on most launch posts, ~8–10 tags)

```
#Sarasudha #SarasudhaRagam #CarnaticMusic #IndianClassicalMusic
#TeluguMusic #SouthIndianCulture #HyderabadMusic #MusicAndCulture
#RootedInTradition #AnnamacharyaKalabharati
```

## Alternate / smaller set (when a post is more visual than textual, ~5 tags)

```
#Sarasudha #CarnaticMusic #IndianMusic #SouthIndianCulture #MusicAndCulture
```

## Branded hashtags (use consistently, every post)

- `#Sarasudha` — the master brand tag, every post
- `#SarasudhaRagam` — only on posts specifically about the Carnatic/Ragam vertical

## Notes

- Don't exceed ~10 tags on a launch post — Instagram allows up to 30, but a
  tight, relevant set reads as more credible than a maxed-out block.
- Don't use tags implying a following or activity that doesn't exist yet
  (e.g. no `#Viral`, `#Trending`, `#MustFollow`).
- Revisit this list once real events/artists exist — city- or artist-specific
  tags (`#CuddapahCulture`, etc.) can be added per-post once there's a
  specific, real thing to tag.
