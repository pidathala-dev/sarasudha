# Heritage sources (internal)

**This directory is internal.** It is not linked from any public page and nothing in it is served as
part of the built site. It exists to catalogue the physical/original materials that
`docs/HERITAGE_CHRONOLOGY.md` and public heritage copy are drawn from — so every dated claim can be
traced back to something real, without necessarily committing private family material to a public
repository.

## Convention

Each source gets a short identifier (`AKB-<TYPE>-<NNN>`) and an entry below recording:

- **Identifier**
- **Description** — a plain description of the physical item, not a transcription of its contents
- **Owner** — who holds the original (e.g. "family," not a named individual, unless the individual
  has agreed to be named publicly)
- **Date scanned/photographed** — if digitised
- **Transcription status** — not started / in progress / complete, and whether any part is still
  ambiguous
- **Where used** — which rows of `docs/HERITAGE_CHRONOLOGY.md` this source supports

**Do not commit the original image/scan of a private family document to this public repository
without explicit approval.** This file documents that a source exists and what it's used for; it
does not reproduce it. If a source is later approved for public display (e.g. as part of the
`/heritage` archive itself, once the Contemporary/Historical Archive content collections have real,
non-demo entries), it goes through the normal archive content pipeline
(`src/content/archive/`, see `docs/CONTENT_GUIDE.md` → "Archive material"), not this directory.

### AKB-CHRONOLOGY-001

- **Description:** Handwritten chronological notes covering Mandapam construction, Jayanti,
  Vardhanti and statue-related activity, approximately 1997–2010. Includes at least one clearly
  legible English-language entry (the 3 August 2010 statue-protection appeal) alongside Telugu
  entries of varying legibility.
- **Owner:** Family (Sarasudha owner's family archive)
- **Date scanned/photographed:** Not yet digitised in this repository — recovered and reviewed as
  handwritten notes.
- **Transcription status:** In progress. Entries for 7 April 1997, 13 April 1997, 22 May 1997,
  25 March 1998, and 7–8 May 2001 are legible with high confidence. A probable 2005 entry has not
  been transcribed with sufficient confidence for public use — see `docs/HERITAGE_CHRONOLOGY.md`.
- **Where used:** `docs/HERITAGE_CHRONOLOGY.md` rows for 1997, 1998, 2001, 2005 (internal only), and
  2010; public copy in `src/pages/our-story.astro` ("The Years That Followed" section) and
  `src/pages/heritage.astro` (archive timeline).
