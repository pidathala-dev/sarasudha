# Heritage Chronology (Internal Source of Truth)

**This file is internal.** It is not linked from any public page and is not rendered as a route. It
exists to track every dated claim about Annamacharya Kalabharati that the public site draws from, its
source, and how confident we are in it — so public copy never says more than the underlying source
supports. See also `docs/HERITAGE_VERIFICATION.md` (legal/registration status) and
`docs/CONTENT_GUIDE.md` (the writing rules derived from this table).

## Primary source

The chronology below is drawn primarily from **AKB-CHRONOLOGY-001** — a handwritten historical
chronology retained by the family, covering roughly 1997–2010. See
`docs/heritage-sources/README.md` for how this and future sources are catalogued. Treat it as
**owner-supplied archival material**, not an independently verified government record.

## The distinction that must always hold

Evidence of **cultural activity** (appeals, commemorations, Jayanti/Vardhanti programmes, a
Mandapam opening) does **not** by itself establish the **legal/compliance status** of the registered
society in those years. Public copy about any date in this table must describe what the archival
record shows happening culturally — never imply continuous registration, active legal standing, or
government recognition. See `docs/HERITAGE_VERIFICATION.md` for the separate, still-unverified legal
status items.

## What's not yet known

- The exact last year of meaningful Annamacharya Kalabharati activity. 2010 is the latest entry
  recovered **so far** — it is not necessarily the last year activity occurred. Public copy should
  say things like "among the records recovered so far…" rather than implying 2010 was definitively
  the end.
- Whether activity was continuous or intermittent between the dated entries above.
- The exact wording/date of the probable 2005 entry (see table).
- Full programme/venue/performer detail for any of the above events — none of this is published
  unless it becomes independently clear from the source.

## Updating this table

When a new source is reviewed (a document, a clearer transcription, a photograph with a caption),
add a new row rather than editing an existing one, and record which source it came from using the
convention in `docs/heritage-sources/README.md`. Only move an item from "internal only" to "publicly
usable" once the underlying handwriting/date/event is legible with high confidence — and only then
update the corresponding public copy in `src/pages/our-story.astro` and `src/pages/heritage.astro`.
